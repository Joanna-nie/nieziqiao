## 🔄 迭代实录（以“出题.md”为例）
- **R1 零约束**：单纯说“根据课文出5道题”，AI出了简答题，且超纲。
- **R2 加格式**：增加【角色】和【表格】要求，AI格式变好，但解析敷衍。
- **R3 定标准**：增加题型配比（2细节+2词义+1主旨）和Few-shot示例，最终产出符合教学要求的题目。
